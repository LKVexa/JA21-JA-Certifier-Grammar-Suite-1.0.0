# R12/MCRT Evidence Profile

R12 captures the stable semantic relation produced by grammar declaration, analysis, validation, transformation, or certification. MCRT captures the causal execution and provenance record needed for replay.

Minimum retained fields:

- source, module, grammar, topic, profile, and validator identities;
- source and semantic hashes;
- operator, relation, state, confidence, and diagnostic status;
- grammar-analysis inputs and outputs;
- policy decisions and capability requirements;
- optimization or migration proof references;
- certificate and signature identity when present;
- deterministic seed, runtime version, schedule, and replay identity;
- Smithson 8S relation class, uncertainty, interaction order, provenance, and claim limitations where the profile is used.
