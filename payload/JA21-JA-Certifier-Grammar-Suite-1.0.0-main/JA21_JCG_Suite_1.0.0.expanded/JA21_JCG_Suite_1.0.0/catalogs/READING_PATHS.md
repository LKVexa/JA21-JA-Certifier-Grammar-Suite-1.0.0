# Reading Paths

## Grammar author
Read textbook Chapters 1–9, then browse the topic atlas and positive/negative script pairs.

## Parser and compiler engineer
Read Chapters 3–15 and 20. Focus on AST binding, conflicts, analysis, validator scheduling, optimization equivalence, and lowering.

## Certification engineer
Read Chapters 15–21. Review evidence records, hashes, signatures, compatibility, migration, profiles, bundles, and certification holdouts.

## Safety and governance reviewer
Read Chapters 1, 15–21. Audit no-network/no-unknown-code policies, stale evidence, unsigned certificates, claim boundaries, and replay evidence.

## Instructor
Use the twelve-week curriculum, textbook, workbook, topic atlas, and all 60 certification holdouts.
