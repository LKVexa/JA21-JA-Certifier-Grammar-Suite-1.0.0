# Governance Charter

## Purpose

The suite exists to make grammar and language certification reproducible, reviewable, and bounded. It shall not represent modeled corpus outcomes as native execution or imply physical validation of the Smithson 8S framework.

## Editorial authorities

- SOPHIA governs semantic truthfulness and claim boundaries.
- CHARLOTTE governs taxonomy, terminology, and information architecture.
- LANDON governs implementation contracts, validators, replay, and release integrity.
- Professor governs pedagogy and assessment.
- Podium governs publication clarity and visual hierarchy.

## Change control

A release-changing edit requires a version increment, manifest regeneration, checksum regeneration, validation rerun, and explicit note when source language, accepted grammar, diagnostics, certificate semantics, policy requirements, or evidence schema changes.

## Native evidence

Only a native implementation may convert modeled compiler, parser, runtime, signature, performance, or certification outcomes into executed evidence. Native evidence must identify tool versions, platform, deterministic seed, profile, hashes, diagnostics, and replay artifacts.
